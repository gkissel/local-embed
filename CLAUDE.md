## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `gkissel/local-embed` (via `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### GitHub Project

For creating, organizing, or updating project work, use the **LocalEmbed** GitHub
Project (#4) and follow `docs/agents/github-project.md`. Native GitHub issue
dependencies are the source of truth for blockers.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
